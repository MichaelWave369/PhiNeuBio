Read the results carefully

The history window is ordinary software that remembers earlier inputs explicitly. The spiking reservoir must encode history in internal state.

The task uses independent random bits. Surrounding bits contain no information that can repair a flipped bit, so the expected best accuracy with the matching noisy input is 1 - noise rate.

Results are software simulations only. Work counters are analytical loop-dimension proxies, not FLOPs or electrical energy.
