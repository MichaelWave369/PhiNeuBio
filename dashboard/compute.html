Test accuracy vs measured CPU time

Horizontal axis is median elapsed milliseconds for a complete probe batch, summarized across seeds. Vertical axis is mean test accuracy. Lower-left isn't automatically better: memory capacity and workloads differ.

What exactly is matched?

Recurrent matrix-entry visits. GRU has three n×n recurrent matrices. Elman, fixed LIF and fixed tanh use one. Hidden widths are chosen so each stays under the declared visit cap.

What isn't matched? The operations done per entry, nonlinearities, trainable parameter counts, training compute, Python interpreter overhead, and conventional memory controls.

Measurements are from the machine that ran the Python script. This webpage cannot measure your CPU or electrical energy by itself.
