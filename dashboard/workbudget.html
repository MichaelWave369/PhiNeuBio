Critical interpretation

Each symbolic work event is weighted one. Real machine costs differ. This is a transparent rule for allocating model epochs, not actual compute parity.

We record recurrent forward/backward terms, readout terms, parameter updates, shared reservoir extraction, and candidate validation.

When a model reaches the maximum epoch count, it may leave unused work score. That unused allocation is visible rather than being hidden.

The burst family flips whole contiguous blocks of observed bits while leaving the clean target sequence unchanged.
