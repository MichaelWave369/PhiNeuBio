Interpretation

Recurrent and nonrecurrent LIF networks use the same simulated neurons. Only a logistic readout learns. The current-input model has no memory; the delayed-input tap has explicit storage and can access the older observed bit directly.

Every candidate sees the same clean labels, observed inputs, and held-out sequences for each seed and delay. Noise affects observed bits, not clean labels.
