# ΦNeuBio

Open-source research into **bio-inspired computation**, spiking neural networks, and reproducible closed-loop learning experiments.

**Status:** Early-stage, software-only research prototype. No biological tissue, clinical claims, or claims of consciousness.

## Project direction

- Begin with deterministic, simulated leaky integrate-and-fire neurons and small reservoir computing experiments.
- Keep data, parameters, seeds, and measurements reproducible.
- Define opt-in interfaces for future PhiStream, PhiMemory9, and other ecosystem integrations.
- Keep any future biological-hardware adapters separate, explicitly authorized, and safety-reviewed.

See the forthcoming initial experiment PR for runnable code, tests, and CI.

## Values

Open research, honest benchmarks, safe experimentation, and careful distinctions between computational behavior and subjective experience.
